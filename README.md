## ✨ 網站功能特色

1. **完整收錄 5 天 40 個行程時刻**：
   - 包含每日精確起訖時間、停留時間長度、MapCode、詳細特色亮點與實用防踩雷 Tips。
   - 保留原行程之「Ocean Tree」往返休整動線與重要生活補給節點。
2. **多維度即時篩選與搜尋**：
   - 按日期切換（全部行程 5 天總覽、Day 1 ~ Day 5）。
   - 按類別標籤篩選（老饕美食、購物商場、景點文化、交通住宿、個人收藏最愛）。
   - 即時關鍵字搜尋（支援中英日文店名、地址、MapCode 與特色標籤）。
3. **互動式路線地圖 (Leaflet Map)**：
   - 地圖自動對齊篩選結果，清楚標記各景點位置與分類顏色圖標。
   - 單日模式自動繪製巡遊路線虛線軌跡。
   - 點擊地圖圖標可直接彈出景點亮點、開啟詳細攻略或跳轉至 Google Maps 導航。
4. **行程景點攻略 Modal 彈窗**：
   - 查看詳細介紹、參觀須知、排隊建議與一鍵複製 MapCode。
5. **旅行錦囊與專屬隨身工具箱 (Travel Toolkit)**：
   - 🌤️ **12月初冬氣候穿搭指南**：均溫 16°C ~ 22°C、洋蔥式穿搭與抗海風必備裝備。
   - 🚗 **日本右駕自駕全攻略**：台灣駕照正本+日文譯本必帶守則、轉彎口訣、MapCode 與還車滿油規定。
   - 🎒 **智慧行李清單 (Packing Checklist)**：可勾選、進度條即時計算、支援新增個人自訂項目，資料自動保存於瀏覽器 LocalStorage。
   - 💴 **日幣即時匯率換算 & 記帳本 (Budget Tracker)**：可自訂匯率換算台幣、記錄旅途開銷明細與自動加總統計。
   - 🍱 **沖繩必吃老饕美食清單 (Food Bucket List)**：經典沖繩麵、糸滿魚市場、敘敘苑海景燒肉、漁民食堂、通堂拉麵、阿古豬炸豬排等。
6. **去趣 ChicTrip 官方深度串接**：
   - 網站頂部、Hero、地圖側欄、專屬推廣區塊皆設有醒目跳轉連結與一鍵複製按鈕。
7. **極致行動端體驗與響應式設計 (Mobile-First UX/UI)**：
   - 📱 **行程清單 / 地圖導航 雙模式切換**：手機端支援一鍵切換「📋 行程清單」與「🗺️ 路線地圖」，地圖下方配有水平滑動景點快捷跳轉 Bar，單手操作流暢直覺。
   - 🚗 **車機 MapCode 一鍵秒複製**：卡片上設有醒目的 MapCode 點擊複製標籤與專屬按鈕，上車輸入 GPS 導航零門檻。
   - 🗂️ **iOS 抽屜式 Bottom Sheet 攻略彈窗**：行動端以原生手感滑動抽屜呈現景點攻略，支援下拉手勢關閉。
   - 📐 **全面適配 iPhone 瀏海屏與安全區域**：支援 `viewport-fit=cover` 與 `env(safe-area-inset-bottom)`，底部導覽列、Toast 提示與回到頂部按鈕不擋手。
   - 🛡️ **防 iOS Safari 輸入框自動放大**：針對表單與搜尋框特別優化，確保點擊輸入時視圖不突兀跳動。
   - 🌓 **深淺色模式無縫切換**：自動適配系統並同步更新行動瀏覽器網址列顏色 (`meta theme-color`)。
   - 🖨️ **列印與 PDF 匯出優化**：紙本手冊排版 `@media print` 專屬樣式。
   - ⚡ 純原生 HTML5 + CSS3 + Vanilla JavaScript，零框架負擔，秒開秒用！

## 🚀 如何在本地開啟與預覽

### 方法一：使用內建 Python 伺服器（推薦）
在終端機中進入專案資料夾並執行：
```bash
cd /Users/xuanli/.gemini/antigravity/scratch/okinawa-trip-2026
python3 server.py
```
系統會自動在預設瀏覽器中開啟 `http://localhost:8080`。

### 方法二：直接以瀏覽器開啟
直接在 macOS 終端機執行：
```bash
open /Users/xuanli/.gemini/antigravity/scratch/okinawa-trip-2026/index.html
```
即可立即在 Safari 或 Chrome 中瀏覽體驗！
