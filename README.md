# 🌺 2026/12 沖繩冬日海風自由行 介紹網站 (Okinawa Road Trip 2026)

這是一個專為「**2026/12 沖繩 5天4夜自駕行程**」量身打造的純前端互動網站與旅行隨身指南。
全面支援**自由客製組合行程**、**真實車程時間自動計算與推算**，並**同時深度滿足 40~60 歲熟齡長輩與 25~35 歲年輕探索族群**的多元旅遊需求。

* **旅行日期**：2026/12/12 (六) - 2026/12/16 (三)
* **核心住宿**：Ocean Tree (海之樹)
* **純前端架構**：零後端依賴，HTML5 + CSS3 + Vanilla JavaScript，所有自訂行程與記帳資料自動加密持久化於瀏覽器 LocalStorage。

## ✨ 網站亮點與核心特色

### 1. 🛠️ 自由客製組合行程 (Custom Planner Studio)
- **多日彈性編排**：可任意增減自訂行程天數（Day 1、Day 2、Day 3...），設定各日出發時間（如 `08:30`、`09:00`）。
- **30 處精選景點庫 (Spot Picker)**：分類篩選（美食、購物、景點、住宿、交通）、年齡取向篩選（熟齡、年輕、高契合）、關鍵字搜尋，一鍵快速加入當日行程。
- **私房自訂地點**：支援手動輸入自訂飯店、秘境居酒屋、停留時長與地址備註。
- **即時調序與節點控制**：各景點自由調整停留時間（15~240 分鐘）、⬆️ 上移、⬇️ 下移、✕ 刪除。
- **4 大經典範本 1 鍵載入**：
  1. 🌟 **官方推薦 5天4夜自駕經典**（完整 40 個停留時刻）
  2. 🧓 **40~60歲 熟齡舒活・海味祈福 3天慢遊**（低步數、平緩動線、清雅海鮮）
  3. 📸 **25~35歲 潮流美拍・巨城爆買 3天極速**（IG懸崖美拍、文青EIBUN、PARCO CITY大買）
  4. 🤝 **跨世代雙贏全家歡樂 2天精華版**（長幼咸宜高契合度黃金路線）
- **多元匯出與備份**：
  - 📋 **一鍵複製完整行程文字**（包含時間表、車程、MapCode 與雙世代重點）
  - 🖨️ **列印 / PDF 匯出**（專屬 `@media print` 純淨紙本手冊排版）
  - 📤 **匯出 JSON 備份檔** / 📥 **匯入本機行程備份**

### 2. 🚗 車程時間自動計算與全日時刻推算 (Driving Time Engine)
- **大圓距離 + 地形修正**：根據沖繩沿海與環島道路曲線，套用 1.28 倍真實繞行修正係數。
- **雙速域自駕模型**：那霸市中心塞車瓶頸區（平均 26 km/h） vs 中北部濱海公路（平均 38 km/h），自動外加 3 分鐘進出停車場與紅綠燈緩衝。
- **短途步行切換**：行駛距離 < 0.8 公里時自動切換為「步行模式」（4.5 km/h，每分鐘 75 公尺）。
- **連鎖時間漣漪推算 (Timeline Propagation)**：只需設定當日出發時間，系統自動向後串接全日所有停靠點的「抵達時刻」、「出發時刻」、「行車距離與車程」及「預估返宿時刻」。
- **即時自駕儀表板與安全警示**：
  - 🚗 預估總行車時間
  - 🛣️ 預估總行駛里程
  - ⏱️ 景點活動總時長
  - 🏁 預計結束返宿時間
  - ⚠️ **90分鐘如廁律警示**：若單趟車程超過 45 分鐘，自動提醒安排道之驛或超商停靠休息，照顧長輩關節與體力。
  - 🌙 **熟齡夜間作息提醒**：若結束時間超過 21:00，提示精簡夜間景點以利長輩充分睡眠。

### 3. 👥 雙世代需求深度適配 (40~60歲熟齡 vs 25~35歲年輕)
- **世代視角切換器 (Generation Perspective Switcher)**：
  - 👥 **跨世代雙視角全覽**：並列雙向重點與全家共融契合度（9.5+/10）及共處秘訣。
  - 🧓 **40~60歲 熟齡舒活視角**：聚焦步數負擔（🟢極低 <500步 / 🟡中度 / 🔴較多）、無障礙平緩動線、冷氣座椅休息區、清淡低鈉海味與熱茶、開運祈福古剎。
  - 📸 **25~35歲 年輕探索視角**：聚焦 IG/Threads 打卡絕景黃金機位、爆紅排隊話題美食（EIBUN、鬆餅）、潮流選品（Workman Plus、Sports Depo、DFS）、夜間微醺與煙火。
- **跨世代共融寶典 (5 大黃金法則)**：
  1. ⏰ **作息折衷律**：約定 08:45-09:00 統一出發，長輩晨起看海，午後商場吹冷氣避暑。
  2. 🚻 **90分鐘如廁停靠律**：主動靠站休息 5 分鐘，免去長輩心理負擔與長途水腫。
  3. 🍜 **餐飲雙軌制**：精選兼具清淡鮮魚熱湯與濃郁肉食之名店（通堂男女麵、魚市場、敘敘苑）。
  4. 🛍️ **分流放風不走散**：商場設定明確集合點（如 Starbucks 或服務台），長輩喝茶年輕人衝刺。
  5. 📸 **美拍耐心券**：年輕人幫長輩拍大方紀念照，長輩體諒年輕人打卡構圖，互敬互重。

### 4. 🗺️ 互動式路線地圖 (Leaflet Map)
- 支援官方行程圖標展示與自訂客製路徑模式。
- 自訂行程模式下自動產生編號路標（1, 2, 3...）並繪製連線軌跡，全景自動對焦（fitBounds）。
- 整合日本車機 MapCode 一鍵複製與 Google Maps 外部即時導航跳轉。

### 5. 🧰 旅行隨身工具箱 (Travel Toolkit)

## 🚀 如何在本地開啟與預覽

### 方法一：使用內建 Python 伺服器（推薦）
在終端機中進入專案資料夾並執行：
```bash
cd /Users/xuanli/.gemini/antigravity/scratch/okinawa-trip-2026
python3 server.py
```
系統會自動在預設瀏覽器中開啟 `http://localhost:8080`。

### 方法二：直接以瀏覽器開啟
直接在 macOS 終端機執行：
```bash
open /Users/xuanli/.gemini/antigravity/scratch/okinawa-trip-2026/index.html
```

### 方法三：使用單檔案便攜版
直接開啟 `dist/okinawa-trip-2026-portable.html`，無需網路伺服器，出國離線亦可順暢使用！
